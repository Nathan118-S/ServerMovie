Scan a disc case
Point a camera at the barcode on an existing case, or at a printed Sandy Server label. If camera access isn't available here, type or wedge-scan the code below — this also works with a USB barcode scanner.
Print labels for your catalog
Pick titles below, then print. Each label has a QR code tied to that title — cut it out and stick it on the disc case. Scanning that label works exactly like scanning the original barcode.

Bulk import titles
One title per line: Title | Year | Genre | Rating | imdbId — only Title is required. Ask Claude in chat to look up the details for a list of movies you own and it'll hand you a block in this format to paste here.
Bulk import posters & banners
Select several image files at once, named to match your titles (e.g. Night Circuit.jpg matches "Night Circuit") — each gets matched and attached automatically, used for both the poster card and the hero banner. This can't reach the web, so use images you already have the rights to use.
Auto-fill posters & descriptions
Looks up every title that's missing a poster or description on OMDb and fills them in automatically — genre, rating, IMDb id, poster art, and a plot summary, all in one pass. Needs an OMDb API key set on the server (free, see README.md) and the Pi to have internet access at the moment you use it — everything else in this app keeps working without either.
